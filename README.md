# dosbox-staging-configs

A collection of DOSBox Staging configurations and DOSBox Staging compatible launcher menus for a variety of DOS flight/space sims, including but not limited to:  

- Aces Of The Pacific (Dynamix)
- Aces Over Europe (Dynamix)
- F-22 Lightning II (NovaLogic)
- LHX Attack Chopper (Electronic Arts)
- Wing Commander I+II (Origin)
- Wing Commander IV (Origin)
